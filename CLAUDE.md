Cargo workspace with 3 members: `seq-decode` (parsers), `seq-bridge` (C ABI surface the daemon consumes), `seq-eqstructs` (Rust mirrors of `../showeq-daemon/src/everquest.h`).
Build: `cargo build --workspace`; tests: `cargo test --workspace`. The integration check is daemon-side — rebuild the daemon with `cmake -DSEQ_USE_RUST=ON -B build` then run `tests/replay/check.sh`; it does a second cmp pass with the Rust decoder enabled and the cross-decoder bytes must match the C++ goldens.
35 opcodes are routed through Rust as of Stage A+8: OP_MobUpdate, OP_DeleteSpawn, OP_ZoneEntry, OP_RemoveSpawn, OP_HPUpdate, OP_MobHealth, OP_SpawnAppearance, OP_ExpUpdate, OP_LevelUpdate, OP_SkillUpdate, OP_ManaChange, OP_Stamina, OP_EndUpdate, OP_Consider, OP_SpawnRename, OP_TargetMouse, OP_Death, OP_ClickObject, OP_Illusion, OP_Buff, OP_Action2, OP_WearChange, OP_ZoneChange, OP_DzInfo, OP_DzSwitchInfo, OP_CastSpell, OP_Action (two-variant: 64b actionStruct + 88b actionAltStruct dispatched on `len`), OP_GroupDisband, OP_GroupDisband2, OP_GroupFollow, OP_CorpseLocResponse, OP_SpawnDoor (per-element 136b doorStruct, daemon iterates the array), OP_GroundSpawn (variable-length NetStream-style), OP_ClientUpdate (both 42b playerSelfPosStruct + 28b playerSpawnPosStruct via hand-rolled bit-extract parsers — the bitfield offsets/widths come from `everquest.h` and the LSB-first packing convention `#pragma pack(1)` produces on x86-64 GCC/Clang), OP_NpcMoveUpdate (variable 13..24b sign-magnitude `BitStream` packing — different convention from the C-struct bitfields, ported from `netstream.cpp`'s `BitStream` MSB-first reader). The whole set toggles together via the daemon's `--use-rust-decoder` boolean; new opcodes just need a `setUseRustX(useRustDecoder)` line in `daemonapp.cpp` plus the parser in `seq-decode`.
`seq-eqstructs/src/bindings.rs` is generated and committed — regenerate after any everquest.h struct change with `python3 tools/gen_eqstructs.py [path/to/everquest.h]` (defaults to the sibling daemon checkout). The script's `ALLOWLIST` mirrors the prior bindgen `.allowlist_type()` set; layout tests in the generated file guard sizes. Trailing `/*offset*/` markers in everquest.h can be stale (e.g. `spawnIllusionStruct` marks 336 but actual size is 332) — the script trusts the per-field declarations and warns on disagreement. No libclang / bindgen dep. **Exception: `spawnPositionUpdate` is hardcoded** — its bitfield pack cannot be parsed generically, so `parse_spawn_position_update()` and the `impl spawnPositionUpdate` accessor block in `emit_rust()` must be updated manually if that struct's layout changes in everquest.h.
